# Pivot forex workspace

A static, light-theme forex chart. The default [biquote](https://biquote.io/docs/) feed supplies streaming prices and tick counts without an API key. The chart and watchlist update from its live SignalR feed, while candles, indicators and volume are reconciled from provider snapshots every minute. The status shows when a fresh tick has not arrived or the connection is unavailable; markets can be closed and data may be delayed. Choose a major or minor pair or XAU/USD and a timeframe. biquote supplies a limited rolling history (about 180 closed 4H bars and 300 closed 1m bars), and availability depends on its feed. Its prices, tick volume, and 4H candle boundaries differ from the TradingView ICE chart, so indicator results will also differ. The fullscreen button expands the chart; Esc exits fullscreen.

Alternatively, choose [Twelve Data](https://twelvedata.com/pricing) in data settings and enter an API key. Its history can be deeper than biquote, but Twelve Data snapshots do not stream in this app and its feed is not TradingView ICE. Symbol and history access depends on its plan and requests consume API credits; free-plan XAU/USD access has not been verified. The key is stored in browser local storage and sent directly to Twelve Data. It is not secret from anyone with access to that browser. Do not use a privileged key on a shared device; use provider-side restrictions if available. Remove it via settings. Neither feed is simulated.

To use [OANDA](https://developer.oanda.com/rest-live-v20/introduction/), select it in data settings and enter a practice or live v20 account ID and personal API token. The browser requests midpoint candles and streams bid/ask quotes directly from OANDA; if the stream fails it falls back to 10-second snapshots. Candles refresh every minute while the tab is visible. OANDA's stream sends at most four prices per second per instrument and can omit intermediate ticks; streamed candles are reconciled with OANDA's candles on refresh. The 28 major/minor currency combinations and XAU/USD appear in the watchlist; symbols unavailable to that account are disabled. Quotes may be stale or unavailable when markets are closed. OANDA account access and instrument availability vary by region and account; OANDA support has not been verified against a real account in this project.

**OANDA tokens can access trading accounts.** Treat a token like a password; use a practice account where appropriate and enter it only on a trusted device. The token and account ID stay in memory in the tab, are sent to OANDA, and are cleared on reload or disconnect. Browser extensions and scripts running on the page can access the token. Never commit it, put it in a URL, or share it in chat. OANDA's terms and account permissions govern its data use.

The chart displays a countdown until the current candle's scheduled close; if no newer candle is available after that time, it says the candle has closed. Use the fullscreen button to expand the terminal (or the page-sized fallback when the browser denies native fullscreen).

## Drawing tools

The left drawing toolbar provides trend, horizontal and vertical lines, rectangles, Fibonacci retracements, and long/short risk-reward drawings. For a position, click entry, then stop/right edge, then target. These are visual annotations only and never place orders. Drawings are stored in browser local storage by source and pair, with Undo to remove the latest; Esc cancels an unfinished drawing. Existing drawings cannot yet be edited individually, and the complete TradingView drawing suite is not included.

## Indicator coverage

The supplied Pine script cannot run directly in Lightweight Charts. This site ports its pivot/ATR-filtered market structure, latest BOS, liquidity sweep, fractals, Fibonacci levels, FVGs, 4H/1D premium/discount classifications, fixed-range volume profile and manual checklist. Higher-timeframe lines are hidden and the CP scanner has been removed. The **Indicator** button configures the main calculation, display and profile inputs; settings persist in this browser.

The port is **not guaranteed to match TradingView**. It uses up to 500 chart/HTF candles, different provider prices and history, and only the latest higher-timeframe snapshot, rather than replaying Pine's `request.security` lookahead behavior on every historical bar. The 4H and daily statuses use the script's separate higher-timeframe BOS range calculation, including its 4H sensitivity adjustment. Some Pine appearance and table-position settings and alternate intrabar timeframes are not exposed. Live biquote ticks update the statuses; otherwise the 1m price is used when enabled and available, and any fallback is reported. Twelve Data still refreshes on demand.

The profile distributes each candle's reported volume proportionally over overlapping price rows, within the active fib leg. For biquote and OANDA it uses **price-update counts**, not traded volume: decentralized forex has no single exchange-wide volume. biquote's 1m window is limited; where it does not cover an entire chart bar, including gaps inside it, the profile falls back to that chart bar's tick count and marks the result approximate. OANDA provides at most 5,000 candles per request, so older 1m history also falls back to chart bars. Thus the POC can differ substantially from TradingView's finer intrabar profile and its data feed. biquote says historical data can originate from multiple feeds; missing or zero tick counts are treated as unavailable, not invented. With Twelve Data, intrabar requests ask for up to 5,000 recent 1m candles and fall back to chart-bar volume when necessary. Twelve Data's EUR/USD demo has no volume, so its profile may be unavailable. The app refuses to draw a profile if required volume is absent or not positive; data errors are shown in the interface.

The checklist is manually checked and is not an automated recommendation. Select its title to collapse or expand it; on narrow screens it starts collapsed to leave room for the chart. This software is not financial advice.

The watchlist displays the supported pairs beside the chart; select a row to change charts and use the search field to filter pairs. biquote starts with a snapshot and updates on streamed ticks. The refresh button retrieves all watchlist quotes; Twelve Data can charge one API credit per symbol, so its quotes are fetched only on explicit refresh and do not stream. An asterisk marks a last-known biquote snapshot, and unavailable quotes are shown as dashes.

## Run and publish

Serve this directory with any static HTTP server, then open its URL. The chart library and fonts are loaded from external CDNs; the browser needs internet access. Do not open the HTML directly as a file, because it uses JavaScript modules.

For GitHub Pages, make the repository public or use an account plan that supports private-repository Pages. Set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**, then merge or push the site to `main`. The included workflow deploys on pushes to `main` or can be run manually. A published Pages site is public even when its source repository is private.

Run the focused calculations tests with `npm test` (Node.js 18+); there are no npm dependencies.
